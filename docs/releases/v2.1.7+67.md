# OpenCode Mobile Next v2.1.7+67

## What's Changed
- **Usage Quota Refresh**: Allow refreshing Antigravity model quota on demand even when the phone agent host session is idle or stopped in the background.
- **Quota Monitor Reliability**: Increased CLI and monitor execution timeouts from 12s/20s to 35s to prevent false timeout failures when fetching quota on mobile devices.
- **Subscription UI**: Added interactive refresh state to the subscription details screen so tapping refresh awaits fresh numbers and provides immediate visual feedback.
- **Account Key Migration**: Support provider fallback during account resolution so the screen seamlessly updates as the subscription upgrades to include the logged-in email.
