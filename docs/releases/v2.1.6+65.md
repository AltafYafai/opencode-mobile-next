# OpenCode Mobile 2.1.6+65

This release adds a visible chat separator to the Conversations view, preventing adjacent conversations from appearing visually combined, alongside Antigravity multi-pool quota fixes and in-app updater improvements.

Change class: fix

## What changed for you

- **Visible Chat Separators on Conversations View.**
  - Added clean, clearly visible dividers between adjacent conversations in the chat feed (`ChatsHomeScreen`), ensuring chats are visually demarcated and no longer look merged or run together.
  - Enhanced `KitDivider` and `KitSliverRowGroup` with prominent divider styling that dynamically adapts contrast for dark mode and light mode while respecting design system guidelines.
- **Real Antigravity Usage Statistics & Quota Tracking.**
  - Fixed an issue where Antigravity usage statistics showed `100% left` on the 5-hour limit and `0%` on weekly limit due to exhausted third-party quota overriding Gemini's active capacity.
  - Fixed an issue where Gemini weekly quota duplicated the 5-hour limit remaining percentage and reset countdown instead of reflecting independent weekly capacity.
  - Accurately tracks independent 5-hour and weekly limits with live countdown timers matching Termux `/usage` output.
- **In-App Updater.**
  - Added complete localization support across Spanish, Japanese, Portuguese, Russian, and Chinese locales for the in-app updater.
  - Fixed release APK packaging and installer integration.
