# OpenCode Mobile 2.1.5+64

This release fixes Antigravity usage statistics so they reflect real quota, remaining percentages, and refresh reset timers matching Termux CLI output, properly separating Gemini Models and Claude & GPT Models, and fixes localization and installer issues in the in-app updater.

Change class: fix

## What changed for you

- **Real Antigravity Usage Statistics & Quota Tracking.**
  - Fixed an issue where Antigravity usage statistics showed `100% left` on the 5-hour limit and `0%` on weekly limit due to exhausted third-party quota overriding Gemini's active capacity.
  - Fixed an issue where Gemini weekly quota duplicated the 5-hour limit remaining percentage and reset countdown instead of reflecting independent weekly capacity.
  - Properly splits and tracks model quota pools matching Termux `/usage`:
    - **Gemini Models:** Real-time 5-hour limit (e.g. 45% remaining) and weekly limit (e.g. 68% remaining) with live countdown timers.
    - **Claude & GPT Models:** Dedicated tracking for Claude Opus/Sonnet and GPT-OSS weekly limits and disabled states.
  - Queries live quota via local Antigravity CLI and Google Cloud Code PA services (`aicode-consumers` project metadata) with resilient local caching and Termux session discovery.
- **In-App Updater and Build Fixes.**
  - Added complete localization support across Spanish, Japanese, Portuguese, Russian, and Chinese locales for the in-app updater.
  - Fixed release APK packaging and installer integration.
