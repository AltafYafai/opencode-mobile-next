# OpenCode Mobile 2.1.5+64

This release fixes Antigravity usage statistics so they reflect real quota, remaining percentages, and refresh reset timers instead of a static 100%, and fixes localization and installer issues in the in-app updater.

Change class: fix

## What changed for you

- **Real Antigravity Usage Statistics & Quota Tracking.**
  - Fixed an issue where Antigravity usage statistics always showed `100% left` regardless of actual quota consumption.
  - The app now queries live quota status directly from Google Cloud Code PA services:
    - **Weekly Limits:** Accurate remaining percentage and reset countdown (e.g. Claude Opus/Sonnet, GPT-OSS).
    - **5-Hour Session Limits:** Remaining percentage and refresh timers.
    - **Model-Specific Quotas:** Dedicated tracking for Gemini 3.8 Flash and tiered models.
  - Matches the live status, remaining quota, and refresh quota timers seen in Termux / CLI sessions.
  - Added resilient local caching and automatic sign-in expiration detection.
- **In-App Updater and Build Fixes.**
  - Added complete localization support across Spanish, Japanese, Portuguese, Russian, and Chinese locales for the in-app updater.
  - Fixed release APK packaging and installer integration.
