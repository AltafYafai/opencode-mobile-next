# OpenCode Mobile 2.1.4+63

This release adds an in-app updater and update checker that alerts on new releases
on every app opening, updates Antigravity CLI to 1.5.3 with full models selection
and usage statistics, and updates the built-in Ubuntu base to 26.04.1 LTS.

Change class: feature

## What changed for you

- **In-App Updater and Update Checker.**
  - The app automatically checks for newer GitHub releases in the background when
    opened or resumed.
  - When an update is available, an update prompt sheet presents the release tag,
    download size, and full changelog.
  - Tapping "Download and update" downloads the APK directly in the app with real-time
    progress (percentage and downloaded megabytes).
  - Once downloaded, the update is directly launched via Android's package installer.
  - A manual "Check for updates" option is available under Settings › Help › About.
- **Antigravity CLI 1.5.3 & Models Selection.**
  - Antigravity agent CLI pinned to version 1.5.3 with checksum verification.
  - Complete list of available models surfaced: Gemini 3.8 Flash (High, Medium, Low),
    Claude Sonnet 4.6, Claude Opus 4.6 Thinking, and GPT OSS 120B Medium.
  - Real-time provider token usage statistics and quota tracking now visible for Antigravity.
- **Ubuntu Base 26.04.1 LTS.**
  - Built-in Linux environment base upgraded to Canonical Ubuntu 26.04.1 LTS.
